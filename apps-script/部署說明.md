## 一、建立 Apps Script 專案（約 5 分鐘）

> 請用 **kinds@baoyan.org.tw**（Workspace 帳號）登入再做，寄信每日配額 1500 封；
> 用一般 Gmail 只有 100 封／日。寄件人會顯示為該帳號，名稱顯示「寶嚴禪寺」。

1. 開 <https://script.google.com> → **新增專案**，專案名稱改成「善財五十三參寄信」。
2. 左側齒輪 **專案設定** → 勾選「**在編輯器中顯示 appsscript.json 資訊清單檔案**」。
3. 依序把本資料夾的檔案內容貼進編輯器（檔名要一致）：
   - `Code.gs`　　　→ 貼到預設的 `程式碼.gs`，並把檔名改成 `Code`
   - `Data.gs`　　　→ 新增指令碼檔案 `Data`，貼上（很長，全選複製）
   - `appsscript.json` → 覆蓋原本的內容（**這步不能漏**，`webapp` 區塊沒貼到的話部署出來會是 404）
4. 存檔。

## 二、第一次授權與測試

1. 上方函式選單選 **`setup`** → 執行 → 依提示授權（會出現「這個應用程式未經驗證」→ 進階 → 前往）。
   執行紀錄會印出剛建立的名單試算表網址，把它加到我的雲端硬碟捷徑方便日後查看。
2. 選 **`testDraw`** → 執行 → 自己的信箱應收到一封抽籤結果信。
3. 選 **`testFace`** → 執行 → 收到面相觀照版本的信。

## 三、部署成網址

1. 右上 **部署 → 新增部署作業 → 類型選「網頁應用程式」**
2. 設定：
   - 執行身分：**我（kinds@baoyan.org.tw）**
   - 誰可以存取：**所有人**（匿名訪客才寄得出信）
3. 部署完複製「**網頁應用程式網址**」（`https://script.google.com/macros/s/AKfycb…/exec`）

## 四、啟用網站上的寄送區塊

把網址貼到 `mailer.js` 第 9 行：

```js
const MAIL_API = "https://script.google.com/macros/s/AKfycb…/exec";
```

commit + push 到 `main`，GitHub Pages 幾十秒後生效。
（`MAIL_API` 留空時，整個寄送區塊不會出現，網站照常抽籤／觀照。）

## 日後維護

**改了籤文或面相文案？** 在專案根目錄跑一次，再把新的 `Data.gs` 內容貼回 Apps Script：

```bash
node apps-script/build.js
```

**改了 `Code.gs`？** 貼回去之後要 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，
網址不變；只按存檔不會更新線上版本。

**貼程式碼的訣竅**（Chrome 自動化／手動都適用）：檔案很長時用剪貼簿最穩——
`LC_ALL=en_US.UTF-8 pbcopy < Data.gs`（**一定要帶 LC_ALL，否則中文會變亂碼**），
再到編輯器對應檔案 ⌘A ⌘V。

**名單在哪？** 試算表「善財五十三參．寄送名單」，每列：時間／姓名／Email／類型／第幾參／
善知識／有緣菩薩／三分數／來源頁／狀態。要匯出名單直接「檔案 → 下載 → CSV」。

## 幾個已經處理好的重點

| 項目 | 作法 |
| --- | --- |
| 不會變成「代寄任意內容」的跳板 | 前端只送**編號**（第幾參、面相等第、菩薩／功課索引），信件內容一律由 `Code.gs` 依 `Data.gs` 重建；姓名會過濾 HTML 與控制字元 |
| 防濫用 | 同一信箱每日上限 5 封、全站每日上限 400 封（`CFG` 可調），並檢查 Gmail 剩餘配額 |
| 隱私 | 面相照片**完全不上傳**，全程在訪客裝置運算，信裡也沒有照片；只保存姓名與 Email，信末附「回信即可取消」 |
| CORS | 前端以 `text/plain` 送出避開 preflight；少數 App 內建瀏覽器讀不到回應時自動改 `no-cors` 補送 |
| 同時多人抽 | `LockService` 上鎖，配額計數不會算錯 |
| 圖片 | 信中的善知識畫卡直接引用 GitHub Pages 上的 `images/NN.jpg`，不佔 Gmail 附件配額 |
