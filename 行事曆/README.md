## 產製方式（可重複執行）
1. `擷取原PDF.py`：以座標方式逐格擷取原始 PDF 的每日內容，輸出 `cells.json`
   （原 PDF 文字層有部分字缺少 Unicode 對應，缺字以 `□` 佔位，於下一步補回）。
2. `產生行事曆.py`：讀入 `cells.json`，補回缺字，套用華嚴海會異動，產生 Excel。
3. PDF 由 LibreOffice 轉出：
   `soffice --headless --convert-to pdf:calc_pdf_Export 2027行事曆_華嚴海會更新版.xlsx`
